# Setting Up Your Computer

Getting started with JetLag means installing a small amount of software on your computer.
This involves a bit of configuration work, and you won't know if you did it correctly until you get all the way to the end of the process.
There's no programming here.
This is just about getting your computer set up, and getting a copy of the JetLag code that you can actually run.
Once you've set it up, you will be able to do all of the chapters of this book in that one copy of the code.
You can also make your own games from that copy (but you might not want to).
