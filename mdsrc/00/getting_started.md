# Chapter 0: Getting Started

This book uses [Jetlag](https://github.com/mfs409/jetlag) to teach game development.

This chapter has two sections:

- **Setting Up Your Computer:** There are a few free programs you need to install before you can use JetLag.
  You'll also need to get your own copy of the JetLag code set up and running.
  Everyone who uses this book should make sure to do these steps.
- **Basic Programming Concepts:** If you don't have a lot of experience with programming, this quick tour discusses key programming concepts, and shows how they are expressed in the TypeScript language.
  It also covers a bit of JetLag's particular programming style.
  If you're in a hurry and you've got some experience programming, you might want to skip this.
  You can always come back to it later if you get stuck on TypeScript syntax.

## A Quick Note About AI

One more thing, before you start.
You're almost certainly going to use AI coding assistants while you work through this book.
That's fine.
They can be very helpful with some parts of game development.
The challenge is that they are not helpful with other parts.
It takes experience to see which is which.

I'll try to give advice about where I think they'll be helpful, and where I think they won't be helpful.
I've also provided an `AGENTS.md` file to help your AI coding assistant understand how JetLag games are written, and where to find this book and the documentation.
Of course, AI coding assistants are developing rapidly.
My advice might not be accurate by the time you read this book.
In fact, it might not even be accurate by the time I finish writing the book!
