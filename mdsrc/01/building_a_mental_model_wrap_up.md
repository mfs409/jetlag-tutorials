# Wrap-Up

The hardest thing about developing software is learning to think the way your programming environment needs you to think.
In this section, you've encountered some new ideas.
They aren't earth-shattering, but they're the building blocks of many kinds of games.

Please don't rush past this.
Take some time to reflect on what you saw.
You saw a simple game built up from scratch, and then you saw some more complete games and tried to guess how they used the camera and gravity.

Along the way, I asked you to think about how you would change the games to make them more enjoyable.
If you haven't done that yet, go back and do it.
Practice copying code into your environment and running it.
Practice putting your ideas into code, playing them, and refining them.
Once you've done that, move on to the next section, where you'll start making a fresh game from scratch.
