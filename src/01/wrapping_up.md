# Wrapping Up

You've analyzed four games that I built, and then you built a small game with your own hands.
That means you already have a working mental model for *any* JetLag game, not just the ones in this book.
Every chapter from here on goes deep on one piece of that model.

For the most part, the rest of the chapters won't ask you to use a feature before it is introduced.
The rest of the chapters will begin by creating new folders, so you can leave `my_game` and `firefly_jar` as-is.

If I can offer just one more piece of advice, it's this:
Don't think you need to finish this book before you start making your own games.
The most important skill is creativity.
You can figure out the code by searching through this book as needed.
But as you build your own games, try to follow the process you just saw.
Figure out the game mechanics first.
Make it fun by playing it and changing numbers.
Find a balance between the gameplay and visuals, so that they grow and evolve together.

And remember: some of the most successful games started as a passion project by one person.
The next great game could be the one you start making today!
