# Chapter 3: Styles of Movement

<img src="../professor_parse_idle.png" alt="Professor Parse" width="72" style="image-rendering: pixelated; float: left; margin: -36px 1em 1em 0;">

In this chapter, you'll steal treasure from a crowd of penguins, and in the process you'll learn that there is more than one way to make something move. The big idea is that tilt, chasing, and following a path are all just different answers to the question "who decides where this actor goes next?"

I'm still writing this chapter, step by step.  In the meantime, you can play the finished game, and read the code and the assets that make it, so that you can run it and change it yourself.
