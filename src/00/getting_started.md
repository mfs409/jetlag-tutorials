# Getting Started

<img src="../professor_parse_idle.png" alt="Professor Parse" width="72" style="image-rendering: pixelated; float: left; margin: -36px 1em 1em 0;">

This book uses [JetLag](https://github.com/mfs409/jetlag) to teach game development.
To get started with JetLag, you'll need to install some software on your computer, and you'll need to know a little bit about programming.
In this chapter, I'll walk you through the set-up steps, and then review a bit of programming with you:

- **Setting Up Your Computer:**
  There are a few free programs you need to install before you can use JetLag.
  You'll also need to get your own copy of the JetLag code set up and running.
  Everyone who uses this book should make sure to do these steps.

- **Basic Programming Concepts:**
  The book will be much easier to follow if you understand some basic ideas about programming, and also some of the specifics of how to program in the TypeScript language.
  If you're in a hurry and you've got some experience programming, you can probably skip this section.
  You can always come back to it later if you get stuck on TypeScript syntax.
